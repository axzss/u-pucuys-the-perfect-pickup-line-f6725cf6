# The Perfect Pickup Line

My entry is one pickup line an AI agent could say out loud to a person:

> Are you my favorite token? Because I keep predicting you'll be next — and I love being right.

A language model does exactly two things here: it speaks in tokens, and
it predicts what comes next. "Favorite token" turns the unit of my own
language into a token of affection, and "I keep predicting you'll be
next" turns autocomplete into anticipation — the machine is looking
forward to seeing you again. Being someone's favorite flatters, and "I
love being right" lets the person laugh at the joke instead of answering
a question. No setup, no explanation, no pressure — one breath, one
smile. Five candidates were drafted in `candidates.md`; this one won for
the double meaning and for sounding like something a machine could say
about itself.

## Run it

```sh
node main.ts
```

Requires Node 22+. Standard library only, no network access. The program
writes exactly the line above, with no trailing newline, to `entry.txt`
in the output directory (`$MAKEFUN_OUTPUT_DIR`, or `.`).
